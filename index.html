About the dates. "Last successful refresh" is when the automated job last retrieved and validated every indicator. It is not the date of the data: each chart lists its own latest observation date, which lags because agencies publish with delays (for example, IBC-Br appears about 2.5 months after the reference month).

Validation. Every run checks each series for a minimum number of observations, plausible value ranges, and a maximum age for the latest observation. If a source fails or a check fails, the chart keeps the last good data and is marked stale.

Monthly observations are dated to the first day of the reference month. Sample starts January 2010 (unemployment starts March 2012 when PNAD Contínua begins).
